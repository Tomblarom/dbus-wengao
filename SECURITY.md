# Security policy

## Reporting

Please report vulnerabilities privately through GitHub Security Advisories. Do not include
real device serial numbers, VRM identifiers, network addresses, credentials, private keys or
unredacted communication captures in a public issue.

## Device safety

The current development version is read-only. Device-write functionality must not be added
without register-level evidence, hard limits, explicit per-device permission, rate limiting,
response validation and readback verification.
